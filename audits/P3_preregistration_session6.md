# P3: Pre-Registration — Session 6 (Fictional-Name Control) and Session 6b (Batch-Size Dose-Response)

**Status:** staged pre-design, archived BEFORE any session-6/6b data collection (2026-10-25, UTC).
Per Section 3.5 of the working paper: this is within-study staged pre-specification, NOT independent
pre-registration (no external timestamp; OSF/AsPredicted deposit is recommended for future sessions).
All contrasts below are reported OUTSIDE the declared five-hypothesis family.

**Motivation (user/referee layer-2 directives, 2026-10-25):**
1. The session-5 swap control separates "concrete name present" from "identity real", but a
   swapped headline pairs natural text with a DIFFERENT REAL firm's identity. The missing cell is a
   FICTIONAL firm name: natural text, a concrete name, no real-world prior.
2. The batch-composition effect is established between compositions; a batch-size-1 baseline is the
   zero point that separates response-level context effects from per-call serving jitter.

## Session 6 — fictional-name control (single sitting, three conditions)

Conditions over the identical 341 in-window headlines, batch size 25, three-way rotated call order
per batch (order rotates by `b mod 3`), protocol verbatim-identical to sessions 1–5, thinking
disabled, default decoding, every call logged with timestamp and served-model ID:

- **N6** — named protocol (anchor; `[RealName] title`), file `llm_scores_s6_named.json`
- **A6** — anonymized v2 (`the company` rewrite + forced verification), file `llm_scores_s6_anonv2.json`
- **F6** — fictional-name protocol: focal identifiers replaced by a fictional firm name from
  `s6_fictional_map.json` (invented name + synthetic ticker; constructed to carry no association
  with any prominent public company), text otherwise natural: `[FictionalName] title-with-name-replaced`,
  file `llm_scores_s6_fictional.json`

Verification pass (forced, pre-collection): A6 and F6 texts must contain zero residual focal
identifiers of the original firm under the session-5 word-boundary check PLUS a substring check on
aliases of length >= 4 (the substring tier exists because the leakage audit of 2026-10-25 found
six session-5 swapped headlines whose concatenated name variant, e.g. "ExxonMobil", evaded the
word-boundary verification). Fictional names must appear in >= 99% of F6 texts (sanity).

### Pre-specified, falsifiable predictions (locked before collection)

- **P6a (the discriminating cell).** Placeholder-rewrite hypothesis: F6 − N6 ≈ 0 (within the
  repeat-noise floor) and F6 − A6 ≈ +2…+3 points. Identity-removal hypothesis: the opposite
  assignment (F6 − N6 ≈ +2…+3, F6 − A6 ≈ 0). Session-5 evidence (swap sits with named) implies the
  rewrite hypothesis; if P6a fails in the direction of the identity-removal hypothesis, the paper's
  de-identification attribution must be re-opened.
- **P6b (replication cell).** N6 − A6 ≈ −2 points (expected range −1…−4), same direction as sessions
  3 and 5; reported under headline-level and 14-cluster-clustered inference.
- **P6c (prediction layer).** Next-day coefficients of N6/A6/F6 aggregates formally equivalent at
  the half-benchmark margin (day-cluster bootstrap), as in every prior identity variant.

## Session 6b — batch-size dose-response (single sitting, one pass per size)

Seeded sample of 50 in-window headlines (seed 20261025, order archived). All passes over the
identical 50 titles in ONE sitting, order B1a (25 singletons) → B25 (2 batches of 25) → B5
(10 batches of 5) → B1b (25 singletons), so the size-1 level is centered in session time:

- **B1** — batch size 1 (50 calls; 25 before + 25 after the other sizes)
- **B5** — batch size 5 (10 calls)
- **B25** — batch size 25 (2 calls)

### Pre-specified predictions

- **P6d (noise decomposition).** If the response-level mood (13% of residual variance, SD≈2.6) is
  generated by cross-headline context within a response, then batch-mean dispersion follows
  Var(batch mean at size k) = mood² + idio²/k, so regressing observed batch-mean variance on 1/k
  must recover a positive intercept (mood² > 0) with the size-1 singleton variance exceeding
  idio². If instead the shared noise is per-call serving jitter independent of composition, the
  singleton variance equals the mood+idio total already measured and the 1/k intercept is
  indistinguishable from the size-25 level — the dose-response will show which.
- **P6e (level zero point).** Mean score at size 1 vs sizes 5/25 for the identical titles:
  two-sided. A level gap between size 1 and size 25 on the SAME corpus would locate the
  batch-composition zero point at "no batch mates at all".
- Exploratory throughout; no family membership; all results reported.
