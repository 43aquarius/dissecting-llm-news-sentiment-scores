# 交付物 C：研究方向比较与推荐研究方案

## C1. 三候选方向比较矩阵

| 维度 | A：LLM 情绪测量增量价值 | B：前视偏差与测量稳定性审计 | C：延续-反转机制识别 |
|---|---|---|---|
| 原创性 | 低——L&T (2026 JFE)、Kang et al. (2025)、Shen et al. (2024) 已覆盖 LLM vs 词典/FinBERT | **高**——post-cutoff 身份效应（G-L 2023 仅 in-sample）+ 价格回声分解 + 推断可靠性，均无先例 | 中——Chan (2003) 已有框架 |
| 数据可行性 | 部分可行：LM 词典可复用；FinBERT 不可行（无模型权重与推理资源，标注"待验证"） | **完全可行**：现有 542 标题 + 价格面板 + 可调用的 LLM | **不可行**：无新闻发布时刻（仅日期）、无买卖价差/订单流 |
| 方法可行性 | 高（现有回归框架） | 高（匿名化重评分、重复调用、bootstrap、差异检验均可代码化） | 低 |
| 证据强度 | 弱：n=240，任何"优于"结论需差异检验，功效不足 | **明确可检验**：H-a 匿名化前后评分一致性/预测力差异；H-b 重复评分稳定性；H-c 回声子样本分解；H-d 选择偏差量化 | 无法识别 |
| 工作量 | 中 | 中-高（新增 2 轮 LLM 评分 + 4 组统计重检） | 高且缺数据 |
| 发表定位 | FRL / 应用 NLP | **Economics Letters（Didisheim 先例）/ FRL / Journal of Financial Data Science** | JFE 级别（达不到） |
| 主要风险 | "无差异"结论无信息量 | 结果可能全部为"无显著差异"——但这本身是有价值的 null result（诚实报告） | 致命：数据不存在 |

## C2. 推荐主方向（B）

**最终研究问题**：在真实新闻-价格面板（2026-07-01~10-14，36 只美股，542 标题）上，LLM 新闻情绪评分的收益预测关系有多大部分可归因于测量层的污染渠道——公司身份先验、评分不稳定性、标题价格回声、新闻覆盖选择——而非文本的语义信息？

**核心假设（全部可证伪，事先声明）**：
- **H1（基线，复检）**：具名 LLM 情绪预测次日收益（原稿 t=2.1 在加强推断下是否存活）。
- **H2（身份效应）**：匿名化（公司名→"the company"）后，(a) 评分分布变化；(b) 预测系数变化。若预测力不降 → 语义信息为主；若显著下降 → 身份先验主导。**注意 G-L 的 in-sample 结果方向（匿名更好，干扰效应），我们的 post-cutoff 窗口方向未知。**
- **H3（稳定性）**：同一提示词重复调用评分的组内相关系数（ICC）；评分→预测结论对重复评分噪声的敏感度。
- **H4（回声）**：含价格回顾语言的标题子样本 vs 干净标题子样本的预测系数差异；控制当日收益后基线系数的衰减幅度。
- **H5（选择）**：新闻覆盖对当日 |收益|/波动的选择效应量化（已验证 t=3.08），及其对外部效度的含义。

**理论依据**：测量误差模型（原稿 §3 可保留骨架但重写）——将 LLM 评分定义为"语义信号 + 身份先验 + 价格回声 + 评分噪声"的加权和，各渠道有可分离的实证签名（匿名化差异↔身份先验；same-day 载荷↔回声；ICC↔噪声）。原稿的注意力-反馈理论模型**降级为动机性讨论**（其命题依赖的 same-day 证据已被污染）。

**对照组与基准**：LM 词典（已有）；中性基准=全零/常数评分（IC 应为 0 的校准检验）；随机化安慰剂（日内置换，已有 p=0.007）；**匿名化条件即身份先验的对照**。

**主要结果指标**：
1. 主检验：具名 vs 匿名化 vs 词典的次日预测系数 + **系数差异检验**（SUR/bootstrap）
2. 评分层：具名-匿名化评分相关、ICC（3 次重复 × 全样本 341）、马赛回归
3. 稳健性：wild cluster bootstrap（Rademacher，企业+日双向）、BH 多重检验校正（申报检验族：5 假设 × 主规格）、价格语言剔除、事件日剔除
4. 经济意义：分位组合（如实报告 t=1.24 不显著 + 交易成本区间 5-15bps 为文献式假设）

**最低可接受证据标准**：若匿名化后预测系数与具名系数差异的 bootstrap 置信区间包含零且两者均边缘显著，论文结论应为"在 240 个新闻 firm-day 的小样本中，无法区分语义信息与污染渠道——LLM 情绪的 OOS 预测主张需要更大样本与匿名化审计才能确立"。**允许 null result 作为最终结论。**

**最主要失败风险**：(i) 匿名化后评分变化太小（GLM 严格执行"只看标题"）→ H2 变成"无信息"检验，但与 G-L in-sample 结果对比仍有发表价值；(ii) 重复评分 ICC 极低 → 基线结论全部动摇，需如实报告。

## C3. 备用方向（A）

若 B 的实验全部失败（LLM 不可调用等），退回"LLM vs 词典增量价值 + 推断可靠性"的纯计量重检论文（数据已冻结，无需新评分）。

## C4. 与"单纯换模型/扩篇幅"的区别

本方案不更换模型、不扩大样本、不增加装饰性内容；它把研究问题从"LLM 情绪是否预测收益"（已答）转向"**该预测关系中多少是测量污染**"（未答），全部新增实验在现有环境可执行，且每个假设有事先声明的证伪标准。
