## 新增实验：会话 4 机制鉴别（预注册后执行）

**设计**：第四会话，运行顺序**反转**（542 构成对照先行、341 基准次行、种子随机洗牌批末行），使时段效应与构成效应方向相反；50 次真实 API 调用一次窗口完成。若构成效应为时段伪影，符号应反转；若复现，则为批次构成本身。

**结果（analysis_v4.py → results_s4.json）**：

| 量 | 值 |
|---|---|
| 构成效应（反转顺序复现） | **+3.50**（聚类 t=2.17, p=0.042）；与 s3 合并 **+3.56（z=3.41）** |
| 同时段跨会话漂移（341 构成） | +0.57（t=0.31，n.s.） |
| 同语料随机重排批 | **+4.72**（聚类 t=2.02, p=0.065，suggestive） |

**结论**：时段漂移被彻底排除（反转顺序下效应复现）；构成效应跨两个会话稳定。

## 机制发现（anchoring_regression*.py → results_anchoring*.json）

| 量 | 值 | 含义 |
|---|---|---|
| 清洁锚定 θ（批友固定成分） | **+0.36（t=4.9）** | 同化锚定真实存在 |
| 非对称性（正批友额外斜率） | **+0.69（t=2.3）**；负批友斜率≈0 | 正向批友上拉、负向不下拉 |
| 伸缩恒等式 | 线性锚定对任何重分批预测水平位移 **恰为 0** | 水平位移只能来自非线性部分 |
| 响应级情绪（每次 API 响应 25 条共享） | SD 2.6，**残差方差的 13%** | 调用是真实聚类单元 |
| 逐条独立噪声 | SD 6.7，87% | 与 H3 within-SD 7.2 精确一致（7.18） |

**诚实定位**：批次效应的**存在性**确立（z≈3–5，两会话、反转顺序）；**机制**定位到响应内部（锚定真实、非对称、线性部分水平中性），但从估计系数到 +3.5 位移的完整定量推导未闭合——论文如实写明。

## 推断修正：调用聚类（reinference.py → results_reinfer.json）

发现：每次 API 调用返回 25 条得分共享响应级情绪 → 标题级配对 t 高估精度。全部会话 3/4 水平对比按批次调用聚类重估：

| 对比 | naive | 聚类修正 |
|---|---|---|
| 身份效应（交错） | t=4.28 | **轮级 t=6.82（p=0.0065）；批次聚类 t=2.73（p=0.017）** |
| 身份效应（剔 V） | t=4.88 | **t=4.83（p=0.0003）** |
| 构成效应 s3 | t=4.55 | **t=2.74（p=0.012）** |
| 构成效应 s4 | t=3.51 | **t=2.17（p=0.042）** |
| 随机重排批 | t=4.48 | **t=2.02（p=0.065）→ 降级 suggestive** |

**所有核心结论存活**（身份先验、构成效应），但显著性口径全部换成保守聚类值并写入论文（表 3、摘要、引言、结论、附录 E/F/G 同步）；随机重排批如实降为 suggestive。
