## P1-2 同会话交错身份配对实验（预注册后执行）— ✅ 完成

**设计**（数据收集前在问题清单中预先声明）：第三会话（2026-10-18 04:54–05:34 UTC，模型 glm-4-plus，逐调用日志含时间戳与模型 ID），同一批 341 条标题，4 轮具名 + 4 轮匿名，轮内 14 个批次按奇偶交替条件顺序（偶批具名→匿名，奇批匿名→具名），协议与 v1/v2 逐字节一致。另加 542 条 v1 批次构成对照（P1-3）。

**结果（analysis_v3.py → results_s3.json）**：

| 量 | 值 |
|---|---|
| 交错身份效应（具名−匿名） | **−2.82**（95% CI [−4.12, −1.53]，t=−4.28，p=2.5e−05；Wilcoxon p=1.6e−06） |
| 逐轮估计 | −3.99 / −2.05 / −2.74 / −2.51（全负） |
| 剔除 V（10 条匿名化 no-op） | **−3.13**（t=−4.88，p=1.6e−06） |
| 调用顺序污染检查 | 具名先行批 +3.34 vs 次行批 +2.27（无伪影） |
| 配对精确匹配率 | 48.5% |

**科学结论变化**：v3/v4 的"身份效应约 1 点、边缘显著、取决于检验"三重表述**升级为确定结论**：身份先验真实、**负向**（具名比匿名悲观约 3 点）、在 >0.99 功效下高度显著。v2 稿的 "+4.75 具名乐观先验" 被最终证伪——其符号本身即会话漂移掩盖的产物。**匿名化方向上移分数，具名方向下移**。

## P1-3 漂移来源鉴别：批次构成 vs 端点 — ✅ 完成

**设计**：同一会话（2026-10-18）内，同一批 341 条标题分别在 v1 的 542 条混批构成与 341 条纯构成下评分（同端点、同协议、同顺序）。

**结果**：
- 构成效应：**+3.61 分**（t=4.55，p=7.5e−06）——同一条标题在 542 混批中比在 341 纯批中平均高 3.61 分
- 加性分解精确成立：+5.79（总漂移）= 1.05（会话1−会话3 @542构成）+ 3.61（构成 @会话3）+ 1.14（会话3−会话2 @341构成）
- **批次构成承载原"会话漂移"的 62%**；端点残差为 ±1 点/会话对的非单调游走

**新发现**：LLM 情绪分数**依赖同批复评分的其他标题**——此前文献未量化的测量效度渠道（候选机制：批内锚定 vs 流内位置，本设计未识别，列为后续实验）。v4 稿"无法将漂移归因于端点或构成"的局限声明**已解决**。

## P1-1 价格语言分类审计（52 条逐条核验）— ✅ 完成

**方法**：结构化四分类规则手册（P 已实现价格 / E 基本面幅度 / D 方向预期 / N 正则误报），逐条人工（LLM 辅助、披露为非独立标注）核验。规则手册与全部 52 条标签存档 priced_classification.json。

**结果（p11_classification_analysis.py → results_p11.json）**：
- 正则精确率：43/52 = **82.7%**（E=3、D=3、N=3，如 "execution short fall"、两条 Walmart "dropped deals" 促销误报）
- 严格 P 分拆：β=0.0475（t=1.61，n=33）vs 正则 0.0470（t=1.80，n=38）——点估计不变
- 回声特征锐化：strict-P 当日 |ret| 361bps vs clean 178bps；误分类组仅 120bps（低于 clean，验证分类本身）
- 无主导性：最大单公司占比 9%，LOCO/逐公司 jackknife 差值符号翻转率 0.00，β 区间 [0.018, 0.059]

**结论**：H4 维持"directional evidence"定性；分类器经自身审计后可靠。
