## Data availability statement
All headlines, all archived score sets (including the interleaved and control sessions), per-call API logs, seeds, prices, scripts, and analysis outputs are available in the public replication package (GitHub: 43aquaris/dissecting-llm-news-sentiment-scores, Release v6.5.0). Every number in the manuscript is generated by deterministic scripts from archived inputs; the full replication package regenerates all tables and figures. The Online Appendix (submitted as Supporting Information) contains Appendices A–K, including the staged-session design documents.

## Generative AI use
The studied scoring instrument is a large language model (GLM-4-Plus, accessed via API). The research pipeline itself — literature collection, scoring runs, analysis code, and manuscript drafting — was operated with AI assistance under the author's direction and control. The author determined the research design and the staged analysis plan, pre-specified the hypotheses and the declared test family, directed each scoring session, verified every reported number against the archived scripts and data, and takes full responsibility for the interpretation and the conclusions. The AI system is not an author, in keeping with journal policy.
