## A3. 独立复核结论

1. **可复现性 ✓**：`analysis.py` 重跑输出与 `results.json` 逐位一致；论文全部表格数字与代码输出一致；6 张统计图重跑一致；LM 词典为真实 Master Dictionary。
2. **双向聚类 SE**：实测 statsmodels 2D groups 语义 ≈ Cameron-Gelbach-Miller 双向聚类（t=2.17 vs 论文 2.10），非致命实现错误；但 35 个公司聚类/59 个日聚类低于渐近舒适区，无 wild cluster bootstrap。
3. **安慰剂检验（新增）**：日内置换情绪 1000 次，置换 p=0.007 —— 信号非纯噪声（原稿未报告此检验，这是新增证据）。
4. **增量预测力（新增）**：控制当日收益后 t=2.10→1.82→1.71（加隔夜收益），p=0.035→0.069→0.087 —— 核心结果对价格回声不稳健。
5. **覆盖选择（新增）**：新闻日与高波动强相关（|ret| t=3.08；新闻数-波动率 corr=0.483）——原稿"无偏差"声明错误。

## A4. 统计与逻辑问题清单（按严重度）

**致命/高**：
- H1 价格回声内生性：15.2% 标题含已实现价格语言（"Rose 14%"、"Dropped by 5%"）；情绪↔当日收益 t=3.33；same_day t=3.43 实为机械相关却被理论化。
- H2 覆盖选择偏差被错误否认（直接与数据矛盾）。
- H3 马赛与异质性的"显著性差异"推断谬误（无差异检验）。
- H4 多重检验（~20 检验，全部边缘显著 0.035-0.058）无任何校正。
- H5 摘要选择性报告（强调 54bps/90bps，隐去 IC t=0.30、logit p=0.20、LS t=1.24）。

**中**：
- M1 "monotone"与数据矛盾；M2 look-ahead 的 size 分组；M3 空洞引用；M4 组合 Welch t 忽略横截面/时序相关；M5 理论命题将内生模式作为验证。

**低**：
- L1 mkt_ew 含被预测公司自身；L2 模型版本/温度未记录；L3 新闻日期仅日粒度。

## A5. 优先解决障碍

1. 缺新闻发布时刻 → 机制类主张（注意力扩散 vs 流动性）不可识别，只能弱化。
2. 缺匿名化对照与重复评分 → 可在本环境**新增实验**解决（LLM 可调用）。
3. 样本仅 240 新闻 firm-day / 70 日 → 功效上限低，任何重构都不能把它写成"高置信度发现"；定位应转向**测量学/方法学贡献**（见交付物 B、C）。
4. FRED/新闻档案受限 → 数据扩充空间有限，诚实报告为限制。

**总体判断**：原稿是一份**可复现但推断与解释超出证据强度**的工作论文。其"测量层"（评分协议、词典对照、管线）质量尚可；其"推断层"（选择性表述、推断谬误、内生性未处理）和"定位层"（作为 L&T 的独立复现+机制发现）不可辩护。重构方向：以测量有效性与前视偏差审计为核心贡献，弱化可交易性主张。
